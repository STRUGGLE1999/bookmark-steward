# 书签归位 · AI Bookmark Steward

让杂乱书签按用途归位，也让每次收藏都知道放在哪里。Chrome Manifest V3 扩展，支持本地规则和自备模型 API，无需注册本工具账号。

## 功能

- **智能收藏**：在当前网页打开弹窗，先推荐文件夹和理由，允许改选，确认后直接收藏。保存后显示完整路径，可打开文件夹或撤销本次收藏。
- **已有书签整理**：读取选定书签栏，按用途生成分类方案，预览并调整后再应用。保留原书签，通过原目录快照支持撤销。
- **可选自动归类**：使用 Chrome 原生收藏后，后台自动判断位置，显示处理记录。默认关闭；希望每次先确认去向，请使用智能收藏。
- **HTML 导入导出**、重复链接提示、中文分类、本地规则或 OpenAI 兼容 API。

## 安装（无需商店付费）

1. 在仓库的 **Releases** 下载 `bookmark-steward-extension.zip`，解压到一个长期保留的文件夹。
2. Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后直接包含 `manifest.json` 的目录，勿选择 ZIP 文件。
5. 点击浏览器工具栏的拼图图标，将“书签归位”固定。

也可以下载本仓库源码 ZIP，解压后选择其中的 `extension` 目录加载。不要删除或移动已加载的扩展文件夹。此版本没有自动更新：以后下载新版并替换文件，再到扩展管理页点击重新加载。

## 首次使用：智能收藏

1. 打开要收藏的普通网页，点击扩展图标，或按 **⌘⇧Y**（Windows/Linux：`Ctrl+Shift+Y`）。快捷键冲突时，可在 `chrome://extensions/shortcuts` 修改。
2. 查看建议目录和理由，在“保存位置”下拉框改选也可以。
3. 点击“确认收藏”，书签直接保存到目标文件夹，不经过书签栏临时中转。
4. 本次弹窗内可查看完整保存路径，点击“打开文件夹”或“撤销本次收藏”。撤销只删除刚创建且未被修改的那条书签，不删除原有书签。

Chrome 原生星标和 `⌘D`/`Ctrl+D` 仍打开原生弹窗。使用上述扩展入口才会先推荐、再确认。暂不支持 `chrome://` 等浏览器内部页面。

## 配置 AI

不配置 API 也能使用本地规则。使用 AI 时，模型费用由你向服务商支付，本工具不代付。

1. 下载仓库根目录的 [`config.example.env`](config.example.env)，复制为 `model.local.env`。
2. 用文本编辑器填入自己的配置并保存：

```dotenv
API_KEY=填入你自己的密钥
BASE_URL=https://your-provider.example
MODEL=YOUR_MODEL_NAME
```

以上三项均需按每个人自己的服务商和账户填写：API_KEY 是自己的密钥，BASE_URL 是服务商提供的 API 根地址，MODEL 是该服务商支持的模型名称。示例域名和模型名只是占位符，不能直接调用。不要把密钥交给不信任的服务商。

3. 在智能收藏弹窗展开“AI 配置 · 仅当前浏览器会话”，选择自己的 `model.local.env`。
4. 勾选发送信息同意项，点击“启用 AI 并重新推荐”；Chrome 请求访问该服务商域名时确认授权。
5. 推荐结果会明确显示“AI 建议”。失败时显示本地建议，请确认后再收藏。

`BASE_URL` 填服务根地址，或以 `/v1` 结尾的地址；不要填完整 `/chat/completions`。本工具会补齐接口路径。配置需使用 HTTPS。

**不要上传真实配置文件、密钥或个人书签。** 仓库仅提供占位模板；`.gitignore` 排除真实 `.env` 配置。智能收藏配置仅存于 Chrome 会话存储，关闭浏览器后需重新载入。禁用后台自动归类不会关闭智能收藏自己的 AI 配置。

## 整理已有书签

1. 弹窗右上角点击“整理与设置”。建议先从 Chrome 书签管理器导出一份 HTML 备份。
2. 选择书签栏，点击“读取当前书签”。
3. 选择“本地规则”或“AI 深度分类”。AI 模式展开后可载入同一配置文件，并确认数据发送。
4. 填写使用场景，生成方案，检查分类理由和待确认项，必要时调整。
5. 确认后应用。扩展保留书签 ID 和网址，旧目录存入其他书签的整理备份；支持撤销上次整理。

保留一次批量撤销快照。整理后若又修改了书签，撤销可能因保护新内容而停止；此时先导出当前状态，再使用原始 HTML 备份手动恢复。卸载扩展会清除撤销快照，请先备份。Chrome 导入 HTML 会新增书签，不会自动替换现有目录。

## 可选：原生收藏后自动归类

在“整理与设置”顶部选择归类方式，勾选开启并保存。AI 方式需先在下方载入 API 配置及发送同意，再保存自动归类设置。新收藏须位于所选书签栏内，约等待 1.2 秒后开始处理；模型可能需要更久。

最近的分类记录会显示目标目录和是否使用 AI；API 失败会明确回退本地规则。低置信度请人工检查。关闭时取消勾选并保存。智能收藏确认保存的书签不会再被此功能移动。

## 隐私与权限

- `bookmarks`：读取目录、创建或移动书签以及执行你请求的撤销。
- `storage`：本地恢复快照、设置和归类记录；会话中保存模型密钥。
- `activeTab`：你主动点击扩展时读取当前网页标题和网址，不读取正文。
- 可选 HTTPS 域名权限：只在你启用自选模型服务时申请。

没有内置 API Key、遥测 SDK 或书签云数据库。调用 AI 会将经过筛选的标题、网站域名和临时 ID 发给你选择的服务商；单条推荐还包含现有文件夹名称。私人文档、内网、控制台及含敏感参数的链接按规则排除，但规则无法识别所有私人内容，请自行检查标题和目录名。服务商接收数据并按其条款处理和计费。

网页端的批量 API Key 只保留在页面内存；扩展的智能收藏和后台 AI 配置保留在 Chrome 会话存储。完整说明见 [`extension/privacy.html`](extension/privacy.html)。

## 开发与验证

需要 Node.js 20+、Python 3（可选静态预览）和系统 `zip` 命令；无第三方运行时依赖。

```sh
npm test
npm run build
npm start
```

预览网页：`http://localhost:4173`。网页只支持导入导出，原生书签读写需要扩展。

- `dist/`：网页及共享逻辑源文件。修改共享文件后运行 build，同步到 extension。
- `extension/`：扩展 manifest、后台、智能收藏弹窗及共享逻辑副本。
- `tests/`：分类、隐私过滤、迁移、撤销、自动归类与智能收藏回归测试。
- `scripts/build.mjs`：同步共享文件，并生成 `dist/downloads/bookmark-steward-extension.zip`。

当前 24 项自动化测试通过；智能收藏已完成种子用户手工验收。第三方模型输出不保证每次一致，批量方案必须先人工预览。此仓库不附带个人书签、私人配置或原始测试数据。
