TWO WAYS TO MAKE ROOM

网页就能试，扩展帮你直接归位。

01 / 无需安装

导入、整理、导出

Chrome 书签管理器 → 右上角菜单 → 导出书签。把 HTML 导入这里，确认分类后导出，再导入 Chrome。

Chrome 导入会新增目录，不会覆盖旧书签。请核对新目录后再清理旧目录。

02 / 想直接整理浏览器？

安装 Chrome 扩展

下载 ZIP → 解压 → 打开 chrome://extensions → 开启开发者模式 → 加载已解压的扩展程序 → 选择解压文件夹。

只申请书签与本地备份权限。模型网络权限在你选择服务商后按需申请。不读取网页正文或浏览记录。

↓ 下载扩展 v0.1开发者模式适合首批试用；当前尚未上架商店，不支持自动更新。应用时保持页面打开，若中断可重新打开撤销。
